# CleanBench-LLM

一个用于比较规则清洗、LLM清洗和混合清洗方法的表格数据评测框架。

当前仓库采用教学式增量开发：模块、类型和接口已经设计完成，并按照 `LEARNING_PLAN.md` 的顺序逐步实现和测试。

## 为什么选择 Python

- pandas适合表格处理。
- LLM SDK和数据科学工具链成熟。
- 实验、统计、绘图和报告可以使用同一种语言完成。
- 这个项目的难点是实验设计和评测可靠性，不是底层性能。

## 架构

```text
src/cleanbench/
├── config.py              # 实验配置
├── domain/                # 核心数据结构
├── io/                    # 数据集与实验产物读写
├── corruption/            # 可控错误注入
├── cleaners/              # 规则、LLM和混合清洗
├── schemas/               # 输出和字段约束
├── evaluation/            # 指标与错误分析
├── experiments/           # 实验编排
└── reporting/             # 图表和报告
```
